# Поиск автозапчастей

Приложение на React и Redux Toolkit. Сначала оно ищет производителей по артикулу, затем загружает предложения и аналоги для выбранного бренда. В таблице показаны цены и остатки по складам.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала. В демо введите артикул `7160500039S` и выберите `MEYLE`.

Для поиска по реальным данным раскройте «Настройка API», введите выданный тестовый ключ и нажмите «Подключить». Ключ хранится в памяти страницы до её перезагрузки. [Документация API Favorit Parts](https://lk.favorit-parts.ru/static/wsprice.pdf)

`npm run build` собирает приложение в папку `dist`.
